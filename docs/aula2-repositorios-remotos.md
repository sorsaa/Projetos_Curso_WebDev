Repositórios Remotos

Um repositório remoto é um repositório armazenado em um servidor, como o GitHub.

Ele permite que várias pessoas trabalhem no mesmo projeto, compartilhem alterações e mantenham um histórico das versões.

## Principais comandos

- `git remote -v`: mostra os repositórios remotos configurados.
- `git push`: envia as alterações para o repositório remoto.
- `git pull`: baixa as alterações do repositório remoto para o computador.
